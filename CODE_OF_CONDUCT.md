# Code of conduct

Be decent. Assume the other person is trying to do good work.

Specifically:

- Critique the code, not the person who wrote it.
- If you think something is wrong, say what and why, with an example.
- "This is wrong" with no path forward is not a review, in a pull request or in a
  gate's output.
- Nobody is expected to know the history of this repository before contributing.
  If a decision looks strange and the comment does not explain it, the comment is
  the bug.

Harassment, personal attacks, and any of the usual behaviours that make people
leave a project are not welcome and will get you removed without much ceremony.

Report a problem to **ajeermahmood@outlook.com**.
